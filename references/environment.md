# 环境与路径

运行前核实当前电脑、用户指定的归档根目录及写入权限。首次使用且未指定目录时，询问用户归档位置；不要猜测或沿用其他人的路径。
每次运行重新检查目录存在、可读写及剩余空间。本 Skill 目录是工具目录，不代表业务项目已经完成。
安装时复制完整 Skill 文件夹到宿主支持的 skills 目录；只有实际安装并核验后才能声称安装成功。`.git` 不参与安装、上传或接手包。

## 飞书配置（可选）

复用用户已授权的飞书连接或现有 CLI 和相关技能，不新建应用、不复制凭证。
目标文件夹由当前用户指定；链接和文件夹 ID 只记录在用户本地控制记录，不写回本公开仓库。
使用前检查当前登录身份、目标目录访问和写入权限，历史同步成功不代表当前版本。
若使用 lark-cli，先查当前版本帮助及相关技能文档；支持时用 `lark-cli auth status --json --verify` 核实身份，用户网盘操作显式 `--as user`。
身份或钥匙串错误时停止云端操作，保留本地结果；不降低凭证存储安全性或擅自重建登录。

## 换电脑

定位用户指定的归档目录，不照搬另一台电脑的绝对路径。重新核验工具和账号授权，只复制 Skill、归档及校验清单，不复制密钥、钥匙串、账号库或登录态。
