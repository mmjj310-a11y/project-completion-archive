# 跨电脑接手要求

使用 assets/archive-template.md 的跨电脑模板，至少包含：
- 项目目标、已确认版本、完成确认、已验证成果和限制。
- 文件入口与目录说明，归档内路径全部使用相对路径。
- 环境表：系统、工具及实际核实版本、插件或 MCP、字体与素材授权。未知项标“未验证”。
- Mac 与 Windows 的路径映射建议；只有系统依赖步骤才分平台编写。
- 恢复步骤：复制资料、核对校验清单、准备必要工具、单独完成登录授权、打开入口、执行最低限度验收。
- 凭证仅写“需要重新授权”和服务名，不包含值，也不默认跨设备登录态通用。
- 对代码项目仅记录已验证命令；对设计项目记录源文件、字体、色彩空间、导出参数与素材缺口。
- 一段可直接粘贴到新会话的接手提示词：要求先读总结与清单，验证实际状态，禁止把历史计划当作事实，明确下一步任务。

不要承诺新电脑零配置运行；逐项区分可直接使用的文案与需要重新配置的工具。
