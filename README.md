# 项目完成归档 Skill

在用户明确确认项目完成后，整理项目总结、可复用方法、提示词、最终成果和跨电脑接手包；可选同步飞书网盘并验证结果。

## 安装与使用

下载本仓库，将完整文件夹命名为 `project-completion-archive`，放入宿主支持的 skills 目录。Codex 本地目录示例：`~/.codex/skills/project-completion-archive`。其他宿主请按其安装规则操作，未逐一验证兼容性。

示例请求：

> 使用 $project-completion-archive。项目「示例项目」v1 已完成，请归档到我指定的完成项目记录目录。本轮只做本地归档。

首次使用需提供项目资料、最终成果及归档位置。需要飞书同步时另行指定目标并完成授权。

## 输出

- 归档清单、项目总结、可复用方法
- 跨电脑接手包、提示词与文案
- 最终成果副本、SHA-256 校验清单
- 本地同步状态记录

## 依赖与边界

- 需要支持读取 Skill、文件操作的 AI 宿主。
- 校验脚本依赖 Python 3，只使用标准库：`python3 scripts/manifest.py <归档目录>`。
- 飞书同步需要用户自行配置已授权工具；本仓库不包含账号或目标目录。
- Codex 侧栏关联依赖宿主提供对应项目与会话工具；工具缺失时报告待完成，不影响保留本地成果。
- 校验脚本只计算文件清单，不是敏感信息检测器；上传前仍须审查内容。
- 不包含无人值守同步服务，也不承诺所有平台零配置运行。

原始业务成果始终保留；不自动判定项目完成，不将计划写成已完成事实。
